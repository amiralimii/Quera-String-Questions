# Quera String Questions
This section contains solutions to string-related programming questions from Quera. Each solution is organized by question number and includes a brief description of the problem.

## Question 1

### Description:
This problem asks you to search through five given strings and find the strings that contain the substring MOLANA or HAFEZ. The numbers of matching strings must be printed in ascending order. If none of the strings contain either substring, NOT FOUND! should be printed.

Solution: [https://quera.org/problemset/10231]

## Question 2

### Description:
This problem is about validating discount codes by comparing their sub-alphabets. The sub-alphabet of a string is the set of different characters that appear in it. For each given discount code, the program must determine whether its sub-alphabet matches the valid discount code and print Yes or No.

Solution: [https://quera.org/problemset/10327]

## Question 3

### Description:
This problem asks you to determine the minimum number of different colors needed to uniquely identify employees who may have the same first name. Each employee is identified using their first name and a color, and employees with the same first name must have different colors.

Solution: [https://quera.org/problemset/10636]

## Question 4

### Description:
This problem asks you to determine the highest score among three people who answer a multiple-choice exam using their own repeating answer patterns. Given the number of questions and the correct answer key, the program must calculate each person's score, find the highest score, and print the names of all people who achieved it in alphabetical order.

Solution: [https://quera.org/problemset/10166]
